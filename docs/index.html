From an investment theme to a stress-tested value chain

Three agents work in sequence. A Researcher maps the theme's value chain from cited sources, a Skeptic attacks every node from three angles in parallel, and a Synthesizer must answer each critique before anything is published. A scheduled Claude session runs the agents every week, so there is no API bill.

Sample data. Live theses appear after the first scheduled Claude run.

How this thesis was built

  1. Input Theme from routines/themes.yaml
  2. Agent 1 Researcher Plans searches per layer, summarizes each source (map), dedups (reduce), audits coverage, drafts the tree.
  3. Agent 2 Skeptic Attacks every node from three angles in parallel. Bottleneck or commodity Substitution risk Priced in
  4. Agent 3 Synthesizer Merges research and critiques, adjusts confidence, answers each critique, writes the memo.
  5. Checks Validator and judge Pydantic schema and golden-spec checks (no LLM), then a rubric score.
